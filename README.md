# Mirror Display AI — Ponte Dev (MVP)

## Descrição do Projeto
O **Mirror Display AI** é um MVP funcional desenvolvido para o bootcamp da DIO, criado especificamente para validar uma solução de transição e capacitação profissional em desenvolvimento de software.

## Links e Demonstração
- **Aplicação Online (Lovable):** [https://mirror-display-ai.lovable.app](https://mirror-display-ai.lovable.app)
- **Repositório do GitHub:** [https://github.com/D771n-ponto/mvp-ponte-dev](https://github.com/D771n-ponto/mvp-ponte-dev)
- **Status da Documentação:** Ativo / Atualizado

## Resumo Executivo
Este projeto utiliza inteligência artificial e automação para guiar profissionais na sua transição de carreira para a área de tecnologia. A plataforma oferece um diagnóstico interativo de competências e direcionamento prático para aceleração profissional.

## Funcionalidades do MVP
- **Landing Page Interativa:** Apresentação da proposta de valor focada na transição para a tecnologia.
- **Formulário de Diagnóstico:** Avaliação interativa para o direcionamento de carreira.
- **Painel Administrativo (Admin Kanban):** Gestão visual e centralizada dos contactos e dados submetidos.
- **Integração com WhatsApp:** Canais diretos e automatizados de comunicação.
